# microservice_crm
This is my first microservice project with sql databases.
Goal of this project was to earn practice experience of working with databases, also to build a microservice structure as mush as possible.
Here we have 4 sections related to 4 VMs, but nothing stops you from build whole project at one server.
1. PHP service which provides proper connection between frontend and DB
2. Python service which was added her for easier administration
3. DB service 
4. Frontend on default HTML+CSS+JS stack
